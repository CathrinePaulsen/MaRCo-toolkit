## Data files
* `projects.csv` contains the 105 Maven projects sourced from GitHub used to compile the dataset of compatible updates,
    and the preliminary evaluation of MaRCo.
* `compatible_dependabot_updates.csv` contains 481 compatible library updates across 167 libraries and 43 Maven projects. The file `compatible_dependabot_updates_with_evaluations.csv` additionally contains the MaRCo evaluations for each update.
* `compatibility_mappings.json`: contains 323 MaRCo-generated compatibility mappings, covering 1252 unique dependency version pairs.
